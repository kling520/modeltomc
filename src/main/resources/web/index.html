体素与写入参数

放置坐标与朝向在左侧每个模型卡片里单独设置。参数自动存在浏览器缓存。预览只读世界，不会改存档。真正写入还是你点“开始写入”那一下；如果没填存档目录，预览会跳过地形，直接只显示模型。“地形预览范围”是每个模型四周额外采样地表的地形宽度，模型相距很远导致预览区域过大时，会自动按列步进降采样以保证流畅。“模型表面光源”开启时会在模型外侧铺一层 light[level=15]，让模型在暗处可见。点“生成模型方块映射”会弹出命名窗口，预览完成后把当前模型用到的方块写进该命名文件（同名文件保留你改过的颜色），并自动切换“映射文件”到它。导出 Litematica 投影也只做体素化并生成文件到项目 exports 目录，不会修改存档；文件内以模型合并后的最小角为原点。Axiom 可直接用 File → Import Schematic 导入 .litematic 投影。

导出只做体素化并生成 .litematic 投影文件到上面的导出路径，不修改存档；文件内以模型合并后的最小角为原点。Axiom 可直接用 File → Import Schematic 导入。“模型表面光源”开启时，投影里也会在模型外侧铺一层 light[level=15]，方便在暗处定位。点“生成模型方块映射”会弹出命名窗口，预览完成后把当前模型用到的方块写进该命名文件（同名文件保留你改过的颜色），并自动切换“映射文件”到它。
